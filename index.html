Google Sheets setup guide

Follow these steps once to connect the app to your Google Sheet. After that, every entry you save is automatically sent to Sheets — accessible on any device.

Step 1 — Create your Sheet

Go to sheets.google.com and create a new blank spreadsheet. Name it Bowser Fuel Log.

Step 2 — Open Apps Script

Inside your Sheet, click Extensions → Apps Script. A new tab opens.

Step 3 — Paste the script

Delete everything in the editor and paste this entire script:

Step 4 — Deploy as web app

Click Deploy → New deployment. Set type to Web app, set Execute as: Me, set Who has access: Anyone. Click Deploy and copy the URL it gives you.

Step 5 — Paste URL above

Paste that URL into the Apps Script URL field above and click Save URL. Then tap Test sync — you should see a success message.
